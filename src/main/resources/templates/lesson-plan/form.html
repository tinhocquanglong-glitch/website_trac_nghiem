Bước 3A · Nhập nội dung từ Word

Chọn file Word và cách nhập. File cấu trúc sẽ lấy chủ đề, bài học và nội dung theo cỡ chữ; file nội dung chỉ ghi vào bài học đã chọn.

Sau khi bấm Lưu thay đổi, hệ thống sẽ đọc file và cập nhật form theo kiểu đã chọn.
